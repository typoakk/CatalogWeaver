# Проверка веб-мониторинга — 16.11.2026

> Исторический отчёт первой реализации. Встроенная общая панель заменена отдельным клиентом на ПК 17.11.2026; актуальная архитектура описана в [monitoring.md](monitoring.md).

Проверки выполнены только на dev, Linux / .NET 10 / PostgreSQL 18.

- Linux build и publish: успешно, без предупреждений компилятора.
- Полный набор: **209 тестов, 0 ошибок, 0 пропусков**, с отдельной тестовой PostgreSQL. Проверены также шифрование подключений, права ключей, CSRF, срок сеанса, частичные HTTP-тела, идемпотентная запись, точные окна 1/5/15 минут, атомарные события успешного завершения и различение первого импорта/обновления. Медленный удалённый сервер не блокирует сбор локальных данных и опрос остальных серверов; параллельные повторные опросы одного подключения исключены.
- Проверено сохранение признака проблемного материала при сохранённом прежнем файле: успешный пустой текст не считается ошибкой, `fieldStatus=retry` и `assetStatus=retry` считаются отдельно от состояния сохранённого файла.
- Два изолированных экземпляра dev в Docker-сети `internal` без выхода в интернет: добавление окружения, автоматическое обнаружение адаптеров и получение удалённого снимка.
- Chrome: вход, все вкладки, 100+5 заданий на двух страницах, фильтр состояния, подробности задания, добавление сервера и ширина 390 px. Ошибок JavaScript, внешних запросов и горизонтального переполнения страницы не обнаружено. Эти проверки использовали явно подготовленные тестовые данные в отдельных тестовых БД.
- Отключение удалённого экземпляра: ошибка связи показана, последний снимок сохранён; после восстановления опрос возобновился. Перезапуск панели сохранил UUID, подключения и историю.
- Действующий dev: прежние 100 успешных заданий и настройки сохранены; другие прикладные сервисы не пересоздавались. Preview Shikimori 52991 с обработкой изображений завершился `completed`: монитор показал 5 запросов и 382010 прочитанных байт. Очередь после preview не изменилась.
- Веб-интерфейс действующего dev отдельно проверен в Chrome: 100 заданий, подробности, HTTP и изображения; ошибок JavaScript не обнаружено. Windows SSH-лаунчер проверен с существующим туннелем и `-NoBrowser`.

На dev сохранены прежний образ, служебный дамп и настройки для отката. Для dev-образа использован Linux publish и уже имеющийся совместимый runtime; выполнение исходного многостадийного Dockerfile требует BuildKit, которого на проверенной машине не было. Проверки staging/prod и длительный нагрузочный прогон не выполнялись.
