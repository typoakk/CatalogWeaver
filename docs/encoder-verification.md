## Реальный самостоятельный цикл

В изолированном Linux-окружении поднят временный Compose-проект с собственной PostgreSQL, собственным томом медиа и отдельным портом. Сборка выполнялась из чистого архива файлов репозитория; конфигурации, созданные во время диагностики, в build context не попадали.

В работающую папку `encoders` добавлен новый модуль PNG с другим уровнем сжатия. Его профиль появился в API автоматически. Адаптер Shikimori переключён на этот профиль через API. Проверена одна карточка, внешний ID `52991`:

1. Preview с обработкой изображения и планом БД завершился успешно; количество постоянных карточек не изменилось.
2. Реальный импорт завершился успешно. Постер сохранён в PNG с фактическим MIME `image/png`, размером 1 351 617 байт.
3. Повтор того же ID оставил одну карточку и один локальный файл. SHA-256 совпал между импортами и с содержимым файла на диске.

Служебная `.env` создана Linux-инициализатором с правами `0600`. Повторный запуск инициализатора сохранил файл и его хеш. Секреты в вывод не передавались. Адаптер после проверки выключен; временные контейнеры, сеть и тома удалены, SSH-туннель закрыт. Это не постоянное развёртывание.

## Найденные особенности

При первой проверке повторного PNG хеш менялся из-за автоматически записываемых ImageMagick дат. Ошибка воспроизведена отдельным native-тестом. В PNG-модуле добавлен `png:exclude-chunk=date,time`; повторные файлы стали побайтно одинаковыми. Параметр исключает служебные даты, сохраняя цветовые профили. Обоснование параметра — в [документации ImageMagick](https://imagemagick.org/script/defines.php).

Один промежуточный Windows-прогон с БД через SSH не прошёл существующую проверку интервала отправки HTTP-запросов в 170 мс. Последующий полный прогон прошёл; проверка также прошла в Linux. Лимитер в этих изменениях не перерабатывался. Это наблюдение не следует считать доказательством исправления или точной диагностики старого timing-теста.

## Границы реализации

- Модули декларативные JSON. Текущий драйвер — Magick.NET / ImageMagick; для другого движка нужен отдельный драйвер программы.
- Новый поддерживаемый runtime выходной формат добавляется JSON без изменения конвейера; это отдельно проверено на BMP. Разрешённые входные форматы остаются JPEG, PNG, WebP, AVIF и GIF.
- Анимация и изображения глубже 8 бит сохраняются в оригинале. JPEG не удаляет прозрачность.
- Тестировался небольшой реальный импорт. Полный обход внешних каталогов не запускался.
- Запись в сторонние таблицы проверялась на отдельной копии данных; рабочие сервисы не использовались как назначение проверки.
