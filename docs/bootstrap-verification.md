# Проверка самостоятельного запуска

Проверен очищенный проект без пакетов конкретного приложения, его моделей и EF Core. Сборка и запуск выполнялись из отдельного чистого Git-клона с одним исходным коммитом, без `.env` и без .NET на Linux-хосте.

| Проверка | Результат |
| --- | --- |
| Сборка solution | Без ошибок и предупреждений |
| Тесты с отдельной PostgreSQL, Windows x64 | 130 успешно, 0 пропущено |
| Те же тесты в Docker/Linux x64 | 130 успешно, 0 пропущено |
| `docker compose up --build -d --wait` без `.env` | Сервис готов |
| Секреты | Созданы автоматически, права файлов `0600` |
| Сохранение адаптера и нового кодировщика через API | Работает с томами по умолчанию |
| Preview одной карточки с изображением | Успешно, без постоянной карточки |
| Импорт одной карточки | Успешно |
| Обычный `down`, затем `up --no-build -d --wait` | Ключ, пароль, настройки и импортированная карточка сохранены |

В проверке использовался отдельный проект Compose и отдельные тома. Резерв свободного места для проверки изображения был настроен под тестовый диск; значение по умолчанию в приложении осталось 5 ГиБ. PostgreSQL и зависимости приложения запускались в контейнерах. Локальный клиент PostgreSQL не использовался для запуска сервиса.

Уменьшение количества тестов относительно исторического отчёта модулей связано с удалением проверок прежней интеграции с конкретным приложением. Проверки очереди, нормализации, изображений, модулей, собственного хранилища и универсального сопоставления с PostgreSQL сохранены. Добавлены проверки bootstrap и чтения секретов из файлов.

В CI добавлен самостоятельный Compose smoke test без `.env`, с запросом готовности, проверкой авторизации и сохранения ключа при повторном bootstrap. Протокол полного прогона находится в [verification.md](verification.md); инструкция пользователя — в [deployment.md](deployment.md).
