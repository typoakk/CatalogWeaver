# Проверка раздельной архитектуры — 17.11.2026

Реализация исправлена по схеме: веб-клиент на ПК независимо получает показатели серверов; каждый сервер отдаёт только собственные данные.

- **Dev / Linux / PostgreSQL 18:** полный набор — 213 тестов, 0 ошибок, 0 пропусков. Новый серверный API не обслуживает веб-клиент, вход в панель или регистрацию других окружений. Клиент с двумя синтетическими источниками использует собственный ключ каждого источника, фиксированные GET-маршруты и независимые фоновые опросы.
- **Windows-клиент:** 11 отдельных тестов, 0 ошибок/пропусков. Проверены пустой запуск без серверного логина, Host/Origin/CSRF, сохранение и повторное чтение защищённых профилей, редактирование без повторного ввода ключа, дубли UUID, неверные ключи, смена идентичности, медленный/недоступный источник и восстановление.
- **Готовый Windows EXE:** автономная single-file сборка запущена на ПК. Панель не требует установленного импортера или PostgreSQL. Используется Windows DPAPI текущего пользователя; фактический ключ dev отсутствует в открытом виде в локальном JSON и не возвращается браузеру.
- **Chrome / действующий dev:** проверены отсутствие формы серверного входа, 100 заданий, подробности, фильтр состояния, все вкладки, редактирование профиля с пустым ключом, окно информации о локальном клиенте и ширина 390 px. Ошибок JavaScript, внешних запросов страницы и горизонтального переполнения не обнаружено.
- **Перезапуск клиента:** профиль dev и его защищённый ключ восстановились на ПК после остановки процесса и смены локального порта интерфейса.
- **Обновление dev:** UUID, ключ мониторинга, история, 100 завершённых заданий, настройки адаптеров и существующие параметры сохранены. Другие прикладные контейнеры не пересоздавались. Серверная регистрация окружений удалена из API; старая таблица не удалялась и не используется. Сохранены прежний образ, настройки и служебный дамп для отката.
- **Лаунчер:** проверены запуск локального EXE, переиспользование правильного SSH-туннеля к источнику и режим без открытия браузера.

Реальные подключения и развёртывание проверены только на dev. Несколько источников проверены независимыми тестовыми ответами; staging и prod не подключались. Исторический отчёт первой версии находится в [monitoring-verification.md](monitoring-verification.md).
