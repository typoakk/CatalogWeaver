# Настройки сервиса

CatalogWeaver читает настройки .NET из `appsettings.json`, переменных окружения и аргументов запуска. В переменных окружения двоеточие заменяется двойным подчёркиванием: `Importer:WorkerCount` → `Importer__WorkerCount`. Числа задаются без разделителей, булевы значения — `true` / `false`.

Изменения настроек процесса требуют его перезапуска. JSON адаптеров и модулей кодировщиков перечитывается автоматически. Параметры конкретного источника, включая частоту запросов и назначения, находятся в адаптере.

## Основные параметры

| Настройка | По умолчанию | Назначение и ограничения |
| --- | --- | --- |
| `ConnectionStrings:ImporterDb` | Не задано | Обязательное подключение к собственной PostgreSQL сервиса. Поддерживает параметры строки подключения Npgsql. |
| `ConnectionStrings:NAME` | Не задано | Необязательное именованное подключение к существующей PostgreSQL приложения; имя выбирается в `destinations.database.connection`. |
| `Importer:PersistenceMode` | `Standalone` | Поддерживается только `Standalone`; назначение БД задаётся JSON, без режимов конкретных приложений. |
| `Importer:AdaptersPath` | `adapters` | Папка пакетов адаптеров. При обычном запуске ищется возле content root, затем возле сборки; относительный путь разрешается от content root. В Compose — `/app/adapters`. |
| `Importer:EncodersPath` | `encoders` | Папка модулей кодировщиков, аналогичное разрешение пути. В Compose — `/app/encoders`. |
| `Importer:MediaRoot` | `data/media` от content root при обычном запуске | Абсолютный корень медиа после разрешения пути. В Compose — `/data/media`. Требуется отдельная папка; адаптер выбирает папку внутри неё. |
| `Importer:ApiKey` | Не задано | Bearer-ключ управляющего API, минимум 32 символа. Для Compose создаётся bootstrap. |
| `Importer:ApiKeyFile` | Не задано | Путь к файлу ключа. Читается, если `ApiKey` не задан. В Compose — `/data/config/api-key`. |
| `Importer:DatabasePasswordFile` | Не задано | Путь к файлу пароля собственной PostgreSQL. Дополняет `ImporterDb`, если пароль в строке подключения отсутствует. В Compose — `/data/config/database-password`. |
| `Importer:Secrets:NAME` | Не задано | Секрет источника, используемый как `{{secret:NAME}}` в запросе адаптера. Например, `Importer__Secrets__SteamApiKey`. |
| `Importer:WorkersEnabled` | `true` | Запускает фоновые worker карточек и discovery. `false` оставляет API и preview доступными; это не отключает весь сервис или обслуживание файлов. |
| `Importer:WorkerCount` | `2` | Одновременные фоновые импорты карточек, от 1 до 16. Discovery имеет отдельный цикл. |
| `Importer:MaximumAttempts` | `16` | Максимальное число неуспешных попыток задания/обхода, от 1 до 32. Постоянные ошибки завершаются раньше. |
| `Importer:LeaseSeconds` | `180` | Аренда задания, от 30 до 3600 секунд. Продлевается heartbeat; не является общим таймаутом импорта. |
| `Importer:ImportTimeoutSeconds` | `1800` | Общий бюджет одной попытки карточки или страницы discovery, от 30 до 86400 секунд. |
| `Importer:RefreshHours` | `24` | Резервный интервал обновления завершённого задания, от 1 до 8760 часов. Обычный worker использует `refreshHours` из снимка адаптера. |
| `Importer:PreviewCount` | `2` | Общий предел одновременных preview карточек и discovery, от 1 до 16; независимо от `WorkerCount`. |
| `Importer:PreviewTimeoutSeconds` | `120` | Бюджет всего preview, включая ожидание свободного preview-слота, от 1 до 3600 секунд. |
| `Importer:RequestTimeoutSeconds` | `45` | Бюджет одного HTTP-запроса от отправки до чтения тела. Значение ограничивается диапазоном 1–300 секунд. Ожидание общего лимитера входит в бюджет задания/preview, но предшествует таймеру самого HTTP-запроса. |

Повторы временных ошибок используют увеличивающуюся задержку; настройки адаптера `rateLimit.requestsPerSecond` и `requestsPerMinute` действуют совместно для API источника, изображений, discovery и preview. Состояние лимитера хранится в PostgreSQL.

## Изображения и место на диске

Все значения байтов указаны в байтах, а `MiB` — в мебибайтах: 1 MiB = 1048576 байт.

| Настройка | По умолчанию | Назначение и ограничения |
| --- | --- | --- |
| `Importer:CoverBudgetBytes` | `236223201280` (220 GiB) | Бюджет опубликованных изображений, положительное число. Название историческое; распространяется на локальные изображения всех ролей. |
| `Importer:MinimumFreeBytes` | `5368709120` (5 GiB) | Резерв свободного места на диске медиа, неотрицательное число. При достижении резерва новые файлы не публикуются. |
| `Importer:MaximumImageBytes` | `8388608` (8 MiB) | Максимальный размер скачанного исходного изображения, положительное целое. |
| `Importer:MaximumEncodedBytes` | `33554432` (32 MiB) | Максимальный размер кандидата после перекодирования, положительное целое. Превышение делает кандидата неуспешным; применяется общий порядок повторов и fallback. |
| `Importer:StagingRetentionHours` | `24` | Минимальный возраст брошенной временной папки для фоновой очистки, минимум 1 час. Активная папка защищена файловой арендой. |
| `Importer:ImageWorkerCount` | `2` | Предел одновременно работающих дочерних процессов обработки изображений, от 1 до 16. Общий для фонового импорта и preview в одном экземпляре сервиса. |
| `Importer:ImageProcessTimeoutSeconds` | `120` | Таймаут одной нативной операции: проверка оригинала, перекодирование или проверка результата, от 1 до 3600 секунд. При превышении дочерний процесс прекращается. |
| `Importer:ImageMemoryMiB` | `256` | Лимит кеша памяти ImageMagick в дочернем процессе, от 32 до 4096 MiB. Это не абсолютный лимит всей памяти процесса. |
| `Importer:ImageDiskMiB` | `512` | Лимит дискового кеша ImageMagick, от 0 до 8192 MiB. |
| `Importer:ImageThreads` | `2` | Лимит потоков ImageMagick в дочернем процессе, от 1 до 16. |
| `Importer:CleanupBatchSize` | `256` | Количество кандидатов в пакете очистки; значение ограничивается диапазоном 1–2000. |
| `Importer:CleanupUnregisteredFiles` | `false` | Устаревший явный режим удаления также незарегистрированных файлов с именами-хешами. Не включайте для общей или ранее использовавшейся папки: сервис не знает владельца таких файлов. По умолчанию очищаются только учтённые собственные публикации. |

Дополнительно код ограничивает размеры изображения: сторона до 8192 пикселей, площадь до 16777216 пикселей. Эти пределы сейчас не являются настройками. Анимация и глубина более 8 бит сохраняются в оригинале. Профили формата и качества находятся в модулях `encoders`, а не в таблице настроек процесса; см. [encoders.md](encoders.md).

Очистка опубликованных файлов запускается примерно раз в час и рассматривает неиспользуемые файлы старше 24 часов. Проверяются ссылки карточек, активные публикации и экспортные резервы. Резервы доставки во внешнюю БД не освобождаются просто по времени: приложение может продолжать ссылаться на файл. Настройки `CleanupBatchSize` и `CleanupUnregisteredFiles` не отключают эту защиту.

Лимиты worker/preview/изображений относятся к одному процессу сервиса. Ограничения контейнера действуют суммарно на сервис и его дочерние процессы. Подбирайте параллельность вместе с доступной памятью и CPU.

## Bootstrap и секреты

`--bootstrap` создаёт файлы `database-password` и `api-key`, если их ещё нет. PostgreSQL для этой команды не нужна.

| Настройка | По умолчанию | Назначение |
| --- | --- | --- |
| `Importer:ConfigurationPath` | `/data/config` | Выделенная папка секретов для `--bootstrap`. |
| `Bootstrap:DatabasePassword` | Случайные 32 байта в hex | Необязательное начальное значение пароля. Существующий файл сохраняется; несовпадающее начальное значение вызывает ошибку. |
| `Bootstrap:ApiKey` | Случайные 48 байт в hex | Необязательное начальное значение ключа API; аналогичная проверка существующего значения. |

На Linux файлы секретов доступны владельцу для чтения/записи. Менять seed после первого запуска недостаточно для ротации: пароль нужно согласованно изменить в PostgreSQL и файле. Секреты и файлы `.env` не включаются в Git, образы или общедоступные отчёты. Резервные копии с секретами требуют соответствующей защиты.

## Переменные стандартного Compose

Значения `.env` подставляются Compose в его конфигурацию; сам сервис не читает произвольную `.env` как отдельный источник. Чтобы передать дополнительную настройку .NET, добавьте её в `environment` через собственный override-файл Compose.

| Переменная `.env` | По умолчанию | Назначение |
| --- | --- | --- |
| `IMPORTER_PORT` | `8770` | Порт API на `127.0.0.1` хоста. |
| `CATALOGWEAVER_IMAGE` | `catalogweaver:local` | Имя собираемого/выбранного образа сервиса. |
| `STEAM_API_KEY` | Пусто | Передаётся как `Importer__Secrets__SteamApiKey`. Нужен для получения списка Steam; не является ключом управления сервисом. |
| `CATALOG_DATABASE_CONNECTION` | Пусто | Подключение приложения с именем `Catalog`. Пустое значение оставляет прямое назначение БД ненастроенным. |
| `IMPORTER_DB_PASSWORD` | Пусто | Необязательный seed bootstrap для нового тома секретов. |
| `IMPORTER_API_KEY` | Пусто | Необязательный seed ключа управления для нового тома. |
| `IMPORTER_WORKERS_ENABLED` | `true` | Включение фонового импорта. |
| `IMPORTER_MINIMUM_FREE_BYTES` | `5368709120` | Резерв места медиа. |
| `IMPORTER_MEMORY_LIMIT` | `1536m` | Суммарное ограничение памяти контейнера импортера. |
| `IMPORTER_CPU_LIMIT` | `2.0` | Ограничение CPU контейнера импортера. |

Предел числа процессов контейнера — 256, время корректной остановки — 30 секунд. PostgreSQL работает отдельным контейнером. Другие параметры Docker и дополнительные ограничения задаются в собственном override-файле.

Пример `compose.settings.yaml` для уменьшения параллельности:

```yaml
services:
  importer:
    environment:
      Importer__WorkerCount: 1
      Importer__PreviewCount: 1
      Importer__ImageWorkerCount: 1
      Importer__RequestTimeoutSeconds: 90
```

```sh
docker compose -f compose.yaml -f compose.settings.yaml up --build -d
```

Сохраняйте одинаковый набор `-f` в последующих командах. Для запуска без Compose ASP.NET Core принимает обычные параметры `--urls` / `ASPNETCORE_URLS`; в образе задан `ASPNETCORE_HTTP_PORTS=8080`. Уровни журналирования настраиваются через `Logging:LogLevel`; не включайте вывод заголовков авторизации и секретных строк подключения.

## Только для тестов

`Importer:AllowHttpForTests=false` — транспортный переключатель, допускающий HTTP в изолированных тестах. Его не следует включать при обычном использовании. Рабочие адаптеры должны использовать HTTPS.

`MEDIA_IMPORTER_TEST_CONNECTION` — переменная тестового проекта, а не настройка рабочего сервиса. Она указывает на отдельную PostgreSQL с `test` в имени БД. Подробнее — [verification.md](verification.md).
