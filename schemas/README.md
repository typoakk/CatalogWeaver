# JSON Schema конфигураций

- `adapter.schema.json` — инструкции адаптера и политики материалов.
- `encoder.schema.json` — модули перекодирования и профили качества.
- `database.schema.json` — назначения в существующей PostgreSQL и рекурсивные выражения сопоставления.

Используется JSON Schema Draft 2020-12. Относительная ссылка из схемы адаптера на схему назначения должна разрешаться из этой же папки. Все три файла входят в поставку сервиса.

Схемы проверяют структуру, имена полей и основные ограничения значений. Сервис дополнительно проверяет существование запросов и переменных, доступность установленного профиля, безопасное расположение файлов, порядок зависимостей и фактическую структуру целевой БД. Успешная проверка схемой не заменяет `/validate` и preview.

В редакторе привяжите схему к `adapters/*/adapter.json` и `encoders/*/encoder.json` через настройки ассоциаций JSON. Добавлять `$schema` в саму конфигурацию не требуется: контракт конфигурации запрещает неизвестные поля. Например, настройка VS Code:

```json
{
  "json.schemas": [
    { "fileMatch": ["/adapters/*/adapter.json"], "url": "./schemas/adapter.schema.json" },
    { "fileMatch": ["/encoders/*/encoder.json"], "url": "./schemas/encoder.schema.json" }
  ]
}
```

`resolvedImageProfile` описывает служебный снимок очереди; в исходном адаптере выбирается `imageProfile`. Список разрешённых нормализованных полей общий для источников и не задаёт названия таблиц или колонок приложения.
